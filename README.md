# Практическая работа №1 — калькулятор и дешифратор

## Запуск в PowerShell

Открой терминал в этой папке. GCC и make уже установлены в MSYS2:

```powershell
$env:Path = 'C:\msys64\ucrt64\bin;C:\msys64\usr\bin;' + $env:Path
make
make run
```

Ручной запуск:

```powershell
.\cmdcalc.exe 41 + 33 111 - 8 22 '*' 5 221 % 111 100 + 13 -k 2
```

Ответы: 74, 103, 110, 110, 113. Строка: `Hello`.
`make clean` удаляет результаты сборки. В Linux используются те же
команды make, ручной запуск начинается с `./cmdcalc`.

## Что где находится

- `main.c` — проверка аргументов, чтение чисел, вывод и освобождение памяти.
- `calc.c` — функции `calculate` и `decode`.
- `calc.h` — объявления этих функций для подключения в `main.c`.
- `Makefile` — сборка только изменившихся файлов; цели `run` и `clean`.
- `.gitignore` — исключение `.o` и исполняемых файлов из Git.

## Как объяснить решение

1. `argc` — количество аргументов, `argv` — массив их текстов.
   `argv[0]` — имя программы. Каждое выражение занимает три аргумента,
   а последние два — `-k` и ключ. Поэтому `(argc - 3) / 3` — число выражений.
2. `readInt` превращает текст в целое через `strtol`.
   `end` показывает, где остановилось чтение. Если остались буквы,
   число пустое или вышло за диапазон `int`, возвращаем 0 — ошибка.
3. `malloc` выделяет массив результатов: число выражений умножаем
   на размер одного элемента. Заранее число выражений неизвестно.
4. В цикле `position = 1 + 3 * i` указывает на левое число.
   Следом расположены оператор и правое число.
5. `calculate` выбирает действие через `switch`. Для `%` проверяет,
   что делитель не ноль. Возвращает 1 при успехе и 0 при ошибке.
   Сам ответ записывается через указатель `result`.
6. `long long` нужен для результатов: произведение двух `int`
   может не поместиться в `int`. Приведение делаем ДО вычисления.
7. `decode` вычитает ключ из каждого ответа. Например,
   `74 - 2 = 72`, а ASCII-код 72 означает `H`.
8. Для текста выделяем `count + 1` байт: по одному на каждый символ
   и один для завершающего `\0`. Проверяем диапазон ASCII: 0–127.
9. `fwrite` выводит ровно `count` символов. Это позволяет вывести
   даже код 0, который при обычном `%s` досрочно завершил бы строку.
   Управляющие ASCII-символы могут быть невидимы в терминале.
10. Каждый успешный `malloc` имеет соответствующий `free`,
    в том числе при ошибках. Это предотвращает утечки памяти.

`&results[i]` — адрес элемента массива. `*result = ...` записывает
ответ по этому адресу. `const` запрещает изменение значения или данных,
`static` у `readInt` делает функцию доступной только в `main.c`.

В `Makefile` `.o` — промежуточные объектные файлы. Они соединяются
в программу. При повторном `make` неизменённые файлы не компилируются.
`.PHONY` означает, что `run` и `clean` — команды, а не имена файлов.
